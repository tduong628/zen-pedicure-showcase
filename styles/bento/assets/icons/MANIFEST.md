# Pedicure Kiosk Icon Family — Manifest

Generated 2026-09-06 via ChatGPT desktop MCP (`mcp__chatgpt-desktop__generate_image`), per the project's ChatGPT-only image-generation house rule. Produced as 5 consistent-style 2x2 icon sheets (one `claude -p` generation call each), then auto-cropped into individual 512x512 square PNGs with a Python/PIL script that detects each circle badge's bounding box for a centered, tight crop.

**Style:** thin, uniform-line-weight line-art icon, centered inside a solid light cream (#F7ECD8) circular badge. Primary line color is deep burgundy (#7A2130); the three botanical sprigs intentionally vary line color (sage green, lavender purple, burnt orange/gold) to visually distinguish scent/ingredient concepts while keeping identical line weight and badge styling. No gradients, no drop shadows, no photorealism, no text, no watermarks — designed to stay legible at small kiosk sizes (~34-68px).
